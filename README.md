# Repositório de Estudos - Desenvolvimento de Software (IFB)

Este repositório documenta minha jornada de aprendizado e os projetos desenvolvidos durante o curso **Técnico em Desenvolvimento de Software** no **Instituto Federal de Brasília (IFB)**. Aqui estão contidos códigos, desafios de lógica e atividades práticas que abrangem as principais áreas do desenvolvimento full-stack.

O objetivo deste espaço é servir como um portfólio do meu progresso acadêmico, demonstrando a aplicação prática dos conceitos teóricos aprendidos em sala de aula, e também como um material de consulta para futuros projetos.

---

## 📂 Estrutura do Repositório

O conteúdo está organizado em diretórios que correspondem às diferentes disciplinas e áreas de estudo do curso.

### 🧠 `Logica-de-Programacao`

A base de toda a programação. Esta pasta contém uma variedade de desafios e exercícios resolvidos, focados no desenvolvimento do raciocínio lógico e na implementação de algoritmos. Os problemas aqui exploram desde estruturas de dados básicas até a resolução de problemas mais complexos.

### ☕ `POO-Java` (Programação Orientada a Objetos)

Aqui se encontram os projetos e exercícios práticos focados nos quatro pilares da Programação Orientada a Objetos utilizando a linguagem Java:
* **Encapsulamento:** Proteção e agrupamento de dados e métodos.
* **Herança:** Reutilização de código e criação de hierarquias de classes.
* **Polimorfismo:** Utilização de uma mesma interface para diferentes tipos de objetos.
* **Abstração:** Foco nos aspectos essenciais de um objeto, escondendo detalhes complexos.
